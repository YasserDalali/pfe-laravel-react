Titre : Plateforme web de gestion et de partage des publications scientifiques
1. Objectif du projet
L’objectif de ce projet est de créer une plateforme permettant aux chercheurs de l’école de gérer et partager leurs publications (articles, conférences, chapitres de livre, etc.), tout en favorisant la visibilité des travaux de recherche au sein des différentes équipes.
2. Description générale
L’application comportera deux principales parties :
•	Partie Administrateur (Directeur de laboratoire) : gère les professeurs, leurs grades, les équipes de recherche, et le suivi des publications.
•	Partie Chercheur : permet à chaque chercheur de gérer son profil, ajouter ses publications et consulter celles de son équipe ou d’autres chercheurs.
3. Fonctionnalités principales
Côté Administrateur / Directeur de labo :
•	Ajouter, modifier et supprimer les professeurs (nom, grade, équipe).
•	Créer et gérer les équipes de recherche (nom de l’équipe, chef d’équipe, membres).
•	Visualiser un tableau de bord avec :
o	Le nombre total de publications par année.
o	Les statistiques par équipe ou par chercheur.
•	Consulter la liste des publications par type (conférence, article, chapitre, etc.).
Côté Chercheur :
•	Se connecter à son espace personnel.
•	Gérer son profil (informations personnelles, grade, équipe, etc.).
•	Ajouter ses publications avec les détails : titre, année, type (conférence, article, chapitre, etc.), lien PDF.
•	Consulter la page d’accueil affichant les publications récentes de son équipe.
•	Consulter les profils et publications des autres chercheurs.
4. Technologies recommandées
•	Backend : PHP (Laravel)
•	Frontend : React.js
•	Base de données : MySQL
•	Outils : GitHub/GitLab pour la gestion du projet
5. Organisation du travail
•	Travail possible en monome, binôme, trinôme ou groupe de 4 étudiants.
•	Répartition suggérée :
o	Gestion des rôles et authentification
o	Développement du tableau de bord et statistiques
o	Interface d’ajout/consultation des publications
o	Design et intégration React
